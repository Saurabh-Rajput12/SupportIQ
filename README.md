# SupportIQ — RAG-Powered GenAI Support Copilot

> **Academic context:** MCA (Data Science) Project  
> **Mandatory Architecture:** HTML5/CSS3/Vanilla JS + Node.js/Express/SQLite + Python/FastAPI/PyTorch/Transformers/FAISS  
> **Version:** 2.0.0 (GenAI RAG Upgrade)

SupportIQ is a human-supervised, enterprise-grade GenAI Customer Support Copilot and triage engine. It transforms raw customer complaints into structured triage signals and grounded AI draft replies using Retrieval-Augmented Generation (RAG) and local Large Language Models (LLMs):

1. **Experiment 1:** NLP Preprocessing and Tokenization (`ml_service/app/preprocessing/`)
2. **Experiment 2:** BERT Intent Classification on BANKING77 (`ml_service/app/intent/`)
3. **Experiment 3:** T5 Conditional Summarization (`ml_service/app/summarization/`)
4. **Experiment 4:** Prompt Engineering with Real LLM (`Qwen2.5-1.5B-Instruct`), Multi-Strategy Prompting (Instructional, Conversational, Chain-of-Thought, Self-Consistency, Few-Shot), Groundedness Auditing, and LLM-as-a-Judge (`ml_service/app/reply_generation/`, `ml_service/app/quality/`)
5. **Experiment 5:** Dense Vector Search and FAISS RAG Retrieval over 77 banking policy articles and historical ticket corpus (`ml_service/app/retrieval/`)

## GenAI Architecture & Pipeline

```text
Customer Ticket
       │
       ▼
[TextCleaner] (strips noise, normalizes unicode)
       │
       ├─► [BERT Classifier] ──► 77-Class Intent Prediction (BANKING77)
       ├─► [DistilBERT]       ──► Binary Sentiment Polarity (SST-2)
       ├─► [Rule Engine]      ──► Explainable Priority (CRITICAL / HIGH / MED / LOW + Reason Codes)
       ├─► [T5 Small]         ──► Executive Ticket Synopsis (max 64 tokens)
       │
       ▼
[MiniLM Embedder (384-d)] ──► [FAISS IndexFlatIP]
       │
       ├─► Retrieves Top-3 Grounding Policies & FAQs (Cosine match)
       ├─► Detects Duplicate / Similar Historical Tickets (score >= 0.90)
       │
       ▼
[RAG Prompt Assembly] (Untrusted Customer Input enclosed in <<< >>>)
       │
       ▼
[Local LLM: Qwen2.5-1.5B-Instruct on MPS / CUDA]
       │
       ├─► Generates Draft Reply (sent: false)
       ├─► Automated Groundedness Semantic Check (sentence claim verification)
       └─► Automated LLM-as-a-Judge Rubric (Relevance, Tone, Safety 1-5)
       │
       ▼
[Express Gateway & SQLite] ──► Persists Reply, Sources, Quality & Audit Trail
       │
       ▼
[Agent Review Workspace] ──► Human inspects Sources, Quality Badges -> Edit / Approve / Reject
```

## Key Architectural Principles & Non-Negotiable Boundaries

- **Human-in-the-Loop AI Governance:** The engine produces **drafts only**. Every response must be inspected, edited, approved, or rejected by an authenticated agent. Approval persists the decision with `sent: false`. Automatic outbound message or email sending is strictly prohibited.
- **Explainable Triage Priority:** Triage urgency is generated by a transparent, versioned rule engine with explicit reason codes, NOT an opaque black-box neural classifier.
- **RAG Knowledge Grounding:** Generative responses are strictly conditioned on retrieved company knowledge articles. Claims unsupported by retrieved documents or ticket text are flagged with groundedness scores and highlighted for human verification.
- **Indirect Injection Defense:** Untrusted customer inputs are isolated inside triple-angle brackets (`<<< >>>`) with instructions prohibiting prompt override.
- **Service Isolation:** Frontend communicates only with Express over REST JSON; Express writes to SQLite (`PRAGMA foreign_keys = ON;`); FastAPI manages inference statelessly with zero database access.

## How to Run the Project

### Terminal 1: Python GenAI ML Service
```bash
cd ml_service
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```
*(Wait until `Uvicorn running on http://127.0.0.1:8000` is displayed)*

### Terminal 2: Node.js Backend & Web UI
```bash
cd backend
node src/server.js
```
*(Wait until `SupportIQ Backend API Gateway running on port 3000` is displayed)*

### Open in Web Browser
Navigate to:
**http://localhost:3000**

Default credentials: `agent@supportiq.local` / `AgentSecurePass2026!`
